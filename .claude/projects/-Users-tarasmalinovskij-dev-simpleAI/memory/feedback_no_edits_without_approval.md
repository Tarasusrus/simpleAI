---
name: no-edits-without-approval
description: Never make code edits without first explaining the plan and getting user approval
type: feedback
---

Always explain the proposed changes first and wait for user confirmation before making any edits.

**Why:** User explicitly rejected an edit and asked for explanation first.

**How to apply:** Before any Edit/Write tool call, write out the plan (what files, what changes, why) and wait for the user to say "go ahead" or equivalent.
