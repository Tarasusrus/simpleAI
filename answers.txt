Ритейл (Интернет-магазин)
#1 — для разграничения доступа из Интернета к публикуемому сервису
Рекомендация: Web Application Firewall (WAF) или Reverse Proxy (например, NGINX + WAF / Cloudflare / F5 BIG-IP).
Почему: Позволяет публиковать сайт в интернете, при этом жёстко контролировать входящий трафик, фильтровать запросы по правилам и скрывать реальный сервер от прямого доступа из интернета.
#2 — для определения и подавления DDoS-атаки на интернет-магазин
Рекомендация: DDoS Protection Service / Anti-DDoS система (Cloudflare, Akamai, Kaspersky DDoS Protection, Arbor Networks или встроенный Anti-DDoS в провайдере).
Почему: Специализированные решения анализируют трафик в реальном времени, отличают легитимных пользователей от ботнетов и автоматически отсекают вредоносный трафик на уровне сети или приложения, не давая магазину «лечь».
#3 — для определения и блокирования сложных WEB-атак (в т.ч. SQL-инъекции)
Рекомендация: Web Application Firewall (WAF) — отдельный или в составе NGINX/Cloudflare/Imperva/ModSecurity.
Почему: WAF имеет сигнатурный и поведенческий анализ, отлично детектирует OWASP Top 10 атаки (SQLi, XSS, Command Injection и т.д.) и блокирует их до того, как они дойдут до приложения и базы данных.
Промышленность (Корпоративная среда)
#1 — для разграничения доступа из Интернета в DMZ
Рекомендация: Next-Generation Firewall (NGFW) — Palo Alto, Fortinet, Check Point, Cisco Firepower.
Почему: NGFW стоит на границе интернета и DMZ, выполняет глубокий анализ пакетов (L7), IPS, контроль приложений и чётко разделяет внешнюю зону от внутренних ресурсов.
#2 — для защиты электронной почты от вирусов и спама
Рекомендация: Mail Security Gateway / Антиспам + Антивирус для почты (Kaspersky Secure Mail, Microsoft Defender for Office 365, Proofpoint, Cisco Secure Email).
Почему: Специализированное решение сканирует все входящие/исходящие письма на наличие вредоносных вложений, ссылок и спама на уровне почтового шлюза, до того как письмо попадёт пользователю.
#3 — для определения и блокирования вредоносного ПО
Рекомендация: Network IPS/IDS или NGFW с включённым IPS-модулем (Palo Alto Threat Prevention, FortiGuard IPS и т.п.).
Почему: Анализирует сетевой трафик в реальном времени, выявляет сигнатуры и аномальное поведение вредоносного ПО (C&C, эксплойты, загрузка троянов) и блокирует его на сетевом уровне.
#4 — для контроля WEB-трафика и URL-фильтрации
Рекомендация: Secure Web Gateway (SWG) или Proxy с URL-фильтрацией (Zscaler, BlueCoat/Symantec, Kaspersky Web Traffic Security, FortiProxy).
Почему: Позволяет контролировать, какие сайты посещают сотрудники, блокировать категории (порно, торренты, фишинг), сканировать скачиваемый контент и предотвращать утечки данных через веб.
#5 — для разграничения доступа между корпоративной сетью и DMZ
Рекомендация: Next-Generation Firewall (NGFW) или Internal Firewall.
Почему: Создаёт чёткую сегментацию между внутренней корпоративной сетью (где хранятся критичные данные) и DMZ. Работает по принципу «всё запрещено, что явно не разрешено», снижая риск распространения атаки из DMZ внутрь.
#6 — для защиты от вредоносного ПО на рабочей станции
Рекомендация: Endpoint Protection Platform (EPP/EDR) — Kaspersky Endpoint Security, Microsoft Defender for Endpoint, CrowdStrike Falcon, ESET.
Почему: Обеспечивает многоуровневую защиту на хосте: антивирус, поведенческий анализ, контроль устройств, sandbox и возможность реагирования на инциденты (EDR)
