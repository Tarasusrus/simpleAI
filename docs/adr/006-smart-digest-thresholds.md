# ADR-006: Smart Digest Thresholds

**Date:** 2026-07-02
**Status:** Accepted
**Issues:** simpleAI-btol (gkyb / 542t / lxye), simpleAI-cx2g

---

## Context

Утреннее напоминание обогащается «умным дайджестом» — тремя инсайт-строками
поверх истории трат (аномалия дня, топ-категории, неделя-к-неделе). Каждая
строка управляется числовыми порогами. Разбросанные по коду «магические числа»
не дают ориентира для тюнинга: непонятно, что двигать при ложных срабатываниях
или молчании.

Паттерн вычислений — ADR-001 (Go on-demand агрегаты, no cache, graceful
degradation при нехватке истории). Этот ADR не про архитектуру, а про **выбор
порогов**: их значения, обоснование и правила подбора.

## Decision

Все пороги живут в **едином именованном `const`-блоке** в
`internal/skills/budget/digest.go` (не в теле функций). Этот ADR — источник
обоснования; при расхождении кода и ADR правится ADR.

### Таблица констант

| Константа | Значение | Смысл | Обоснование |
|---|---|---|---|
| `baselineDays` | `30` | Окно среднего дневного расхода для аномалии | Месяц сглаживает недельную сезонность; согласовано с горизонтом ADR-001. |
| `minLedgerDays` | `14` | Гейт возраста: моложе — аномалию не показываем | На молодом ledger'е 30-дневный бэйзлайн не наполнен → отклонение мусорное. 2 недели — минимум для грубой опоры. |
| `anomalyThreshold` | `0.25` | Мин. |отклонение| вчера от среднего для заметки | Дневной шум трат высокий; порог грубее трендовых ±3% из ADR-001, чтобы не «кричать» на обычные колебания. |
| `wowNoisePct` | `0.5` | Ниже этого |WoW| в % — «≈ как на прошлой» | Изменение, округляющееся до 0%, показывать стрелкой ↑/↓ бессмысленно. |
| `topCategories` | `2` | Сколько категорий в строке топа | Две даёт сигнал «на что ушло» без шума; при <2 категориях строка опускается. |

### Правила тюнинга

- **Много ложных ⚠️ (аномалия срабатывает на норме)** → поднять
  `anomalyThreshold` (напр. 0.30–0.40).
- **Аномалия молчит на явных всплесках** → снизить `anomalyThreshold`.
- **«Мусорные» аномалии в первые недели** → поднять `minLedgerDays`.
- **Средний смещён редкими крупными тратами** → это ограничение варианта (b):
  знаменатель — 30 календарных дней, не дни-с-данными. Честный знаменатель
  требует стор-метода активных дней (отложено; см. epic btol).
- **WoW дёргается на копейках** → поднять `wowNoisePct`.
- Пороги — **не** конфиг и **не** env: меняются кодом + этим ADR, чтобы
  изменение проходило ревью (значения влияют на UX уведомлений).

## Invariants (context, не тюнится порогами)

- Доставка напоминания не зависит от дайджеста: под-инсайт падает молча.
- Пусто вчера → `""` (до вычисления любых инсайтов).
- Окна дат якорятся UTC-midnight от календарной даты в `loc`.
- Категории сводятся кросс-валютно (в RUB) перед ранжированием.

## Consequences

- Один файл, один блок — единая точка правки; ADR-006 объясняет «почему».
- Значения намеренно консервативны: лучше промолчать, чем дать ложный сигнал.
- Переход на честный знаменатель (дни-с-данными) — будущая ревизия этого ADR.
