# ADR-024: Mail-worker отключён — инструмент недоработан

- **Статус:** Accepted (решение владельца 2026-11-12)
- **Дата:** 2026-11-12

## Контекст
В процессе `simpleai.service` раз в час работал mail-worker (`internal/mail`): читал почтовые ящики
(Gmail API, IMAP) и слал выжимки в Telegram. Инструмент недоработан, владелец попросил остановить его насовсем.

## Решение
- Запуск mail-worker убран из `cmd/app/main.go`: процесс больше не открывает почту, даже если в конфиге
  остались аккаунты.
- Пакет `internal/mail` и отдельный `cmd/worker` остаются в коде, но нигде не запускаются и не деплоятся.

## Чтобы вернуть
Сначала доработать инструмент, затем вернуть запуск отдельным решением (новый ADR).
