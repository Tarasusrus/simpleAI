# SimpleAI

Простой агент с базовой инфраструктурой для обработки чеков, RAG и каналов ввода.

## Что есть сейчас
- CLI‑агент, который принимает запросы из stdin и отвечает через LLM.
- База данных Postgres + pgvector и миграции.
- Ingestion для чеков (receipt, items, RAG документы).
- Воркеры:
  - `cmd/worker` для почтового дайджеста.
  - `cmd/embeddings` для генерации эмбеддингов RAG.
  - `cmd/telegram` — телеграм‑фасад (текст + сохранение вложений).

## Основной флоу
1) Принять данные (CLI или Telegram).
2) Сохранить чек и позиции.
3) Построить документы для RAG.
4) Сгенерировать эмбеддинги.
5) Делать retrieval и строить промпт для LLM.

## Как запустить
- База:
  - `docker compose up -d`
  - `make migrate-up`
- Telegram‑бот:
  - заполнить `.env` (токен, chat ids)
  - `go run cmd/telegram/main.go`
- Embeddings:
  - `go run cmd/embeddings/main.go -limit 100 -batch 20`

## Статус
Проект в активной разработке. Следующий фокус — RAG пайплайн по тратам и контракты плагинов.
